# Pixel Cafe 비공식 한국어 패치 v0.8.0

이 패치는 개인이 제작한 **Pixel Cafe 비공식 한국어 패치**입니다.

본 프로젝트는 비상업 팬 프로젝트이며, Baltoro Games의 공식 프로젝트나 공식 고객 지원 서비스가 아닙니다. Pixel Cafe와 원본 게임 콘텐츠에 관한 모든 권리는 Baltoro Games 및 각 권리자에게 있습니다.

## Pixel Cafe 소개

커피 한 잔을 만드는 짧고 분주한 순간과, 한 사람의 삶과 기억을 따라가는 이야기가 한 게임 안에 담겨 있습니다.

**Pixel Cafe**는 아케이드 스타일의 타임 매니지먼트와 비주얼 노벨을 결합한 게임입니다. 작은 마을을 떠나 대도시 카르스토크에서 살아가는 주인공 픽셀을 따라 여러 가게에서 일하고, 손님들의 주문을 처리하며, 가족과 일, 관계 속에서 자신의 자리를 찾아가는 과정을 만나게 됩니다.

### 게임 특징

- **타임 매니지먼트와 스토리의 결합**  
  음료와 음식을 빠르게 준비하는 매장 운영 파트와 픽셀의 삶을 다룬 이야기 파트가 번갈아 진행됩니다.

- **서로 다른 10개의 매장**  
  가게마다 주문과 조리 방식, 작업 환경이 달라집니다. 새로운 레시피를 익히고 장비를 활용해 몰려드는 손님을 상대해야 합니다.

- **도전적인 추가 스테이지**  
  기본 스테이지 외에 50개의 선택형 나이트메어 레벨이 준비되어 있습니다.

- **세 세대에 걸친 이야기**  
  현재와 과거를 오가며 픽셀의 눈으로 가족의 기억을 따라갑니다. 세 세대에 걸친 감정적인 이야기를 픽셀 아트 연출로 풀어냅니다.

- **집 꾸미기와 수집 요소**  
  할머니의 오래된 집에 가구를 들이고 포스터를 모아 원하는 모습으로 꾸밀 수 있습니다.

- **장면의 분위기를 살리는 음악**  
  Arkadiusz Reikowski가 작곡한 오리지널 사운드트랙이 매장과 이야기의 서로 다른 감정을 이어 줍니다.

### 이런 분께 권합니다

- 바쁜 요리·서빙 게임을 좋아하는 분
- 픽셀 그래픽과 서사 중심 게임을 좋아하는 분
- 가족, 성장, 일과 인간관계를 다룬 이야기에 관심 있는 분
- 기본 스테이지를 익힌 뒤 더 어려운 도전에 나서는 것을 즐기는 분

## 제작 도구 사용 고지

이 패치 제작에는 OpenAI의 ChatGPT 및 Codex 환경에서 `GPT-5.6 Sol`과 `GPT-6 Astra`를 범용 도구로 사용했습니다. 번역 초안 작성과 교정, 문맥 검토, 게임 데이터 분석, 작업 스크립트 작성, 패치 적용, 정적 검증과 문서 작성 등 제작 전반에 활용했습니다.

번역 방향, 용어, 문체, 글꼴 구성, 적용 범위와 배포 여부는 제작자가 직접 검토하고 결정했습니다. AI 도구의 출력은 그대로 자동 배포하지 않고 검수·수정 과정을 거쳤습니다.

ChatGPT와 Codex 및 위 모델의 사용은 Baltoro Games 또는 OpenAI가 이 패치를 공식 제작·승인·보증한다는 뜻이 아닙니다.

`v0.8.0`은 한국어 번역과 역할별 한글 글꼴 구성을 적용한 공개 베타 버전입니다. 번역과 화면 표시는 이후 검수 및 제보에 따라 계속 수정될 수 있습니다.

## 설치 전 주의사항

1. Pixel Cafe를 완전히 종료합니다.
2. Steam에서 설치된 게임의 Build ID가 `16578917`인지 확인합니다.
3. 패치가 교체하는 파일을 게임 폴더 밖의 별도 위치에 백업합니다.
4. 지원하지 않는 버전에는 패치를 적용하지 않습니다.

이 패치는 정품 Steam판 Pixel Cafe가 설치된 사용자를 대상으로 합니다. 게임 구매나 접근 제한을 우회하는 기능은 제공하지 않습니다.

## 설치 방법

> 아래 내용은 현재 검증된 수동 ZIP 설치 방식입니다. 공개 배포 형식이 차이 패치 방식으로 변경되면 이 항목도 함께 수정합니다.

1. Steam 라이브러리에서 Pixel Cafe를 오른쪽 클릭합니다.
2. **관리 → 로컬 파일 보기**를 선택합니다.
3. 게임이 실행 중이면 종료합니다.
4. `Pixel Cafe_Data` 폴더의 패치 대상 파일을 별도 위치에 백업합니다.
5. GitHub Releases에서 받은 공식 패치 ZIP의 내용을 게임 설치 폴더에 풉니다.
6. 파일 교체 여부가 나오면 교체합니다.
7. 게임을 실행하고 기존 스페인어 언어 선택지를 선택합니다.

한국어는 기존 스페인어 언어 ID `6`을 사용합니다. 패치 적용 중에는 해당 스페인어 선택지가 한국어로 사용되며, 기존 스페인어 표시는 유지되지 않습니다.

## 업데이트 방법

게임을 종료한 뒤 새 버전의 공식 패치 ZIP을 같은 게임 설치 폴더에 적용합니다.

게임 본편이 업데이트되었다면 바로 덮어쓰지 말고, 저장소의 지원 Build ID와 공지사항을 먼저 확인해 주세요.

## 제거 및 복구 방법

- 설치 전에 직접 만든 백업 파일을 원래 위치에 복원합니다.
- 백업이 없다면 Steam의 **설치 파일 무결성 검사**를 실행합니다.
- Steam 무결성 검사는 패치 파일을 원본 게임 파일로 되돌릴 수 있습니다.

패치 배포물에는 복구용 원본 백업을 별도로 포함하지 않습니다.

> 패치 적용 후 백업 복원 또는 Steam 무결성 검사를 이용한 삭제·복구 절차는 아직 별도 검증되지 않았습니다.

## 알려진 사항과 제외 범위

- 영어 fallback 531개와 의도적 빈값 2개를 유지합니다.
- 모든 하드웨어, 해상도와 게임 분기에서의 동작을 보증하지 않습니다.
- 게임 업데이트 후에는 패치가 호환되지 않을 수 있습니다.
- 일부 화면에는 원문 또는 미번역 이미지가 남아 있을 수 있습니다.

## 검증 상태

다음 절차로 깨끗한 설치 환경의 기본 동작을 확인했습니다.

1. 기존 게임 제거
2. 잔여 설치 폴더 수동 삭제
3. Steam을 통한 신규 설치
4. 배포 후보 ZIP 덮어쓰기
5. 게임 실행 및 한국어 출력 확인

설정 화면에서 `한국어` 선택과 픽셀 UI 글꼴이 정상적으로 표시되는 것을 확인했습니다. 확인 화면에서는 두부 문자, 명확한 글자 잘림이나 겹침이 발견되지 않았습니다.

이 결과는 모든 게임 분기, 모든 장문 대사, 모든 해상도와 하드웨어 환경의 검증 완료를 뜻하지 않습니다. 발견되는 실제 화면 문제는 화면 전체 문맥과 함께 제보해 주세요.
